# Maintained examples

- [Daiban](daiban.aml): bounded native courtyard study with multilevel circulation. Dimensions are estimates; it does not establish whole-building reference fidelity.
- [Dust II](../demos/dust2/scene.aml): approximate playable CS2 blockout with independently checked elevation, collision and route contracts. See [reference notes](../reference/dust2/README.md).

Validate, preview or build either AML source with `npm run levelspec -- <command> <source>`. Focused fixtures and the CLI starter belong to SuperSpec; sample-map acceptance lives in `tests/engine/`. Sources use meters and right-handed Z-up coordinates.
