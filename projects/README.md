# Working projects

Keep editable AML sources and companion evidence here; use ignored `generated/` for reproducible builds. The maintained public examples are [Daiban and Dust II](../examples/README.md).

See the [transfer notes](../docs/TRANSFER.md) for clean-checkout commands and known
test failures. Original prop models are retained in each asset project's
`source-models/`; [their inventory](source-models.json) records hashes. They are
source assets, while disposable captures, reports and caches stay outside Git.
