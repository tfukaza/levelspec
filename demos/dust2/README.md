# Dust II

Open `scene.aml` with SuperSpec's **Open AML and companions** control, or run
`npm run levelspec -- preview demos/dust2/scene.aml` from LevelSpec. This scene
has no companion files.

The complete map is an approximate playable CS2 blockout with independently
checked elevation, collision and route contracts. Its source is byte-identical
to the former `examples/dust2.aml`; see the [reference notes](../../reference/dust2/README.md)
for evidence, remaining warnings and fidelity limits.
