# AML authoring

`levelspec_aml::read` opens existing AML as an editable draft with source-linked
diagnostics. `levelspec_aml::compile` emits AML XML from a draft and checks the
result using SuperSpec's shared AML reader. An editor or a person can also supply
AML XML directly to SuperSpec. Its native and Wasm hosts use the same reader.

[AML schema](../../superspec/schema/aml.xsd)
